# APES CIC Codex + JetBrains Bootstrap

This repository is the APES CIC Codex agents template, and the same guidance is
applicable to JetBrains-assisted workflows. Before planning, editing,
reviewing, committing, or running repository work, load and follow:

1. `.agents/AGENTS.md`
2. Any task-relevant local guidance such as `README.md`, `CONTRIBUTING.md`,
   `.codex/CODEX_ENVIRONMENT_SETUP.md`, package files, Composer files,
   build files, task files, and configuration files.

If local guidance conflicts, follow the stricter APES CIC safety, privacy,
branching, validation, documentation, Cloudron LAMP, public-folder, release,
and no-secrets rules unless the user explicitly approves a safe exception.

Core rule:

```text
No issue decision, no branch decision, no direct work on main, no state changing Git action without approval.
```

If `.agents/AGENTS.md` is missing, stop and ask before doing implementation
work.
